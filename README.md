# Komunifind — Find Your Community

Direktori komunitas Indonesia. Jelajahi komunitas di kotamu, lihat event terdekat,
dan daftar langsung dari halaman event. Setiap komunitas dikelola panitianya sendiri.

## Fitur

- 🔍 **Jelajah tanpa akun** — cari komunitas by nama, filter kategori & kota
- 📅 **Event & pendaftaran online** — login Google, daftar event, pantau status di "Pendaftaranku"
- 🛠️ **Dashboard panitia** — kelola halaman komunitas, buat & terbitkan event, atur kuota, approve/tolak peserta
- 👑 **Admin pusat** — buat komunitas dan assign panitia
- ✉️ **Notifikasi email** — info pendaftaran diterima, disetujui, ditolak, atau event dibatalkan
